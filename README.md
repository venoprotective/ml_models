## 🎯 О проекте

Этот проект содержит **полные реализации с нуля** (где-то рассмотрены и библиотечные формы) нескольких классических алгоритмов для классификации цветков ириса по известному [набору данных Iris](https://archive.ics.uci.edu/ml/datasets/iris).

**Ключевые особенности:**
- ✅ Все алгоритмы реализованы вручную (только NumPy для вычислений)
- ✅ Визуализация разделяющих границ для любого классификатора
- ✅ Модульная архитектура для легкого расширения
- ✅ Сравнительное тестирование всех моделей

## 🤖 Реализованные алгоритмы

| Алгоритм | Описание | Особенности |
|----------|----------|-------------|
| **Adaline** | Адаптивный линейный нейрон | SGD, MSE, линейная активация |
| **Decision Tree** | Дерево решений | Критерии Джини/Энтропия |
| **Logistic Regression** | Логистическая регрессия | One-vs-Rest, градиентный спуск |
| **Perceptron** | Классический персептрон | Пороговая активация, дельта-правило |
| **SVM** | Метод опорных векторов | Базовый SVM/with kernel trick |
| **k-NN** | k-ближайших соседей | Евклидова |

## 📈 Результаты

На стандартном наборе данных Iris (4 признака, 3 класса) все модели показывают высокую точность:

| Модель | 🎯 Точность | ⏱️ Время обучения |
|--------|:-----------:|:-----------------:|
| **Adaline** | ≈ 97% | ⚡ Быстро |
| **Decision Tree** | ≈ 95% | ⚡ Быстро |
| **Logistic Regression** | ≈ 98% | ⚡ Быстро |
| **Perceptron** | ≈ 93% | ⚡ Очень быстро |
| **SVM** | ≈ 97% | 🐢 Средне |
| **k-NN (k=3)** | ≈ 97% | 🚀 Мгновенно |

> **ℹ️ Примечание:** Точность может незначительно варьироваться в зависимости от разбиения данных и гиперпараметров.
